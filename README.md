# Юридический кабинет И. М. Шаповалова

Сайт юридического кабинета для представления услуг, публикации новостей и
приёма обращений клиентов. Посетитель может ознакомиться с направлениями
работы и ценами, отфильтровать услуги по категориям, перейти к публикациям и
отправить заявку через встроенную Яндекс Форму.

## Возможности сайта

- Главная страница с информацией о кабинете, услугах, новостях и контактах.
- Отдельная страница услуг с фильтрами и адаптивной таблицей цен.
- Страница заявки со встроенной Яндекс Формой.
- Страницы с проектами политики обработки персональных данных, согласия и
  локальных документов.
- Адаптивная вёрстка и маршрутизация между страницами.

## Технологии

React, React Router и Vite. Приложение не использует собственный backend;
заявки отправляются через Яндекс Форму.

## Запуск и проверка

```bash
npm install
npm run dev
```

Для production-сборки выполните `npm run build`. Проверка кода запускается
командой `npm run lint`.

> Страницы юридических документов пока содержат проекты, требующие проверки и
> утверждения. Перед приёмом заявок необходимо подтвердить сведения об
> операторе и настройках обработки данных, а также проверить наличие в форме
> отдельного обязательного согласия на обработку персональных данных.
