# Юридический кабинет И.М. Шаповалова

Стартовая основа приложения на React и Vite с общим layout и маршрутизацией
через React Router.

## Структура

- `src/components/Layout.jsx` — общий каркас сайта: шапка, навигация, подвал.
- `src/pages/` — компоненты страниц.
- `src/App.jsx` — таблица маршрутов.
- `src/main.jsx` — точка входа; `BrowserRouter` включает маршрутизацию.
- `/local-acts` — список публичных документов.
- `/privacy-policy` — проект правил обработки персональных данных.
- `/personal-data-consent` — отдельный проект согласия для формы.

Страницы правовых документов сейчас являются черновиками: официальный адрес
ИП, домен сайта и параметры используемых сервисов нужно подтвердить до начала
сбора персональных данных. Не считайте эти страницы юридическим заключением
или готовым комплектом документов.

## Как добавить страницу

1. Создайте компонент в `src/pages`, например `ContactsPage.jsx`:

   ```jsx
   function ContactsPage() {
     return (
       <section className="page-content">
         <p className="eyebrow">КОНТАКТЫ</p>
         <h1>Связаться с нами</h1>
       </section>
     )
   }

   export default ContactsPage
   ```

2. Импортируйте его в `src/App.jsx` и добавьте вложенный маршрут внутрь
   маршрута с `Layout`:

   ```jsx
   <Route path="contacts" element={<ContactsPage />} />
   ```

   Страница будет доступна по адресу `/contacts` и автоматически появится
   внутри общего layout.

3. Чтобы добавить ссылку в шапку, используйте `NavLink` из
   `react-router-dom` в `src/components/Layout.jsx`:

   ```jsx
   <NavLink to="/contacts">Контакты</NavLink>
   ```

Для внутренних переходов используйте `Link` или `NavLink`, а не обычный `<a>`,
чтобы браузер не перезагружал приложение. Маршрут `*` в `src/App.jsx` показывает
страницу 404 для неизвестных адресов.

## Команды

- `npm run dev` — запуск локального сервера разработки.
- `npm run lint` — проверка ESLint.
- `npm run build` — production-сборка.
